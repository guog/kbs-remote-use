# 产品需求文档 (PRDs) 目录说明

本目录用于存放项目的核心产品与业务需求说明文档（PRD）。任何针对新业务模块的功能定义、用户场景描述和集成限制，均在此目录下记录。

## 🏷️ 文档规范

1.  **模板使用**：任何新 PRD 均应基于本目录下的 [template.md](template.md) 模板进行起草。
2.  **命名规则**：统一采用 `prd-[三位数字]-[英文描述].md` 的小写短横线命名法。
    *   例如：`prd-001-gitlab-wiki-stateless-mcp.md`
3.  **编号体系**：遵循数字自增流水号（`001`、`002`...），模板文件本身（`template.md`）不参与编号。

## 🗂️ 文件树说明

*   `template.md`：通用 PRD 标准格式模板（不落数字编号流水）。
*   `prd-001-gitlab-wiki-stateless-mcp.md`：首期交付项目——GitLab Wiki 无盘检索系统 PRD。
