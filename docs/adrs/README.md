# 架构决策记录 (ADRs) 目录说明

本目录用于存档本项目在研发演进中做出的所有重大技术架构决定的决策记录（ADR）。用于确保团队的技术选型决策历史有据可查、可追溯，减少团队重沟通成本。

## 🏷️ 文档规范

1.  **模板使用**：任何新架构决议文件均应基于本目录下的 [template.md](template.md) 模板进行起草。
2.  **命名规则**：统一采用 `adr-[三位数字]-[英文描述].md` 的小写短横线命名法。
    *   例如：`adr-001-mcp-vs-skill-integration.md`
3.  **编号体系**：遵循数字自增流水号（`001`、`002`...），模板文件本身（`template.md`）不参与编号。

## 🗂️ 文件树说明

*   `template.md`：通用 ADR 决策过程及优劣权衡标准格式模板。
*   `adr-001-mcp-vs-skill-integration.md`：首期架构决策记录——选择 MCP 协议还是本地静态 Skill 的对比抉择。
